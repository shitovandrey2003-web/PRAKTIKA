
Программа находит сумму отрицательных элементов массива, расположенных между максимальным и минимальным элементами (границы не включаются).

Как запустить

1. Убедись, что установлен Python 3.
2. Склонируй репозиторий или просто скачай файл main.py.
3. Запусти командой:

python main.py

4. Введи размер массива и сами элементы. Программа выдаст результат.

Пример работы

Введите размер массива N: 7
Введите элемент 1: 5
Введите элемент 2: -3
Введите элемент 3: 2
Введите элемент 4: -1
Введите элемент 5: -7
Введите элемент 6: 4
Введите элемент 7: 8

Массив: [5.0, -3.0, 2.0, -1.0, -7.0, 4.0, 8.0]
Индекс макс. элемента (8.0): 6
Индекс мин. элемента (-7.0): 4
Границы поиска: от индекса 4 до 6
Сумма отрицательных элементов между ними: 0.0
